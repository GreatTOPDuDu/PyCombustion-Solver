# Contributing to PyCombustion-Solver

Thank you for your interest in contributing! We welcome bug reports, feature requests, and pull requests.

## How to Contribute

1.  **Fork the repository** and create your branch from `main`.
2.  **Install dependencies**: `pip install -e .[test]` (if applicable) or just `pip install -e .`.
3.  **Make your changes**. Ensure your code is readable and documented.
4.  **Run tests**: `pytest` (make sure all tests pass).
5.  **Submit a Pull Request**. Provide a clear description of your changes.

## Code Style

- We follow standard Python conventions (PEP 8).
- Please add type hints to new functions.
- Add docstrings (NumPy style preferred) for new modules/functions.

## Reporting Issues

Please use the GitHub Issues tab to report bugs or suggest features. Include as much detail as possible (OS, Python version, error logs).
